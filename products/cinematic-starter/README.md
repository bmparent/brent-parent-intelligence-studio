# Eidos Cinematic Starter — 1.0
An original glass navigation and cinematic hero starter in plain HTML, CSS, and JavaScript.

## Included
- index.html: accessible semantic page, working in-page navigation, hero, three content sections.
- styles.css: responsive glass header, CSS-only ambient artwork, typography, reduced-motion and forced-colors support.
- script.js: mobile navigation with Escape, outside-click, and desktop-resize handling.
- LICENSE.txt: commercial use terms for one finished website.

## Start
Unzip all files into the same folder and open index.html in a browser. No build, install, account, API, or paid font is needed. Upload the folder to any static host when ready.

## Make it yours
1. Change the five color variables at the beginning of styles.css.
2. Edit the wordmark, headline, page description, content, and contact information in index.html.
3. Keep navigation href values matched to section IDs. Do not remove button labels, aria-controls, or the skip link.
4. Optional: replace the CSS-only ambient artwork with your own licensed image. Keep a dark overlay behind text. Supply width and height attributes and descriptive alt text for meaningful images; decorative images use alt="".
5. Connect a contact provider if you need a form. The example contact section does not send anything.
6. Test keyboard navigation, 320px-wide phones, portrait and landscape, 200% browser zoom, reduced motion, and your final contrast choices.

## Platform notes
This is a standalone starter, not an InkSoft, Shopify, WordPress, or React plugin. A developer can adapt the markup to those platforms; integration work is not included. Avoid copying an entire document into an existing platform's content editor. Scope the styles and adapt the header around the platform's own navigation and cart.
