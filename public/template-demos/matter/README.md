# Matter — Developer source v1

Useful objects with a visible hand. An independent studio exploring clay, timber, and the texture of everyday life.

Start with [INSTALL.md](INSTALL.md). Six linked static pages including legal notes,
one signature interaction, original artwork, and no mandatory build.

Status: release candidate. Prices and availability are controlled by the catalog.
No connected booking, payment, ticketing, emergency dispatch, or message server.
