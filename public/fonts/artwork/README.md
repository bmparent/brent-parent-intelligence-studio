# Artwork font

DM Sans from Google Fonts, SIL Open Font License 1.1 (see OFL.txt). Latin and punctuation subset, original variable axes retained. Source: https://github.com/google/fonts/tree/main/ofl/dmsans

Supported axes: {"opsz": {"min": 9.0, "default": 9.0, "max": 40.0}, "wght": {"min": 100.0, "default": 400.0, "max": 1000.0}}

The same bytes are embedded in studio SVG and animation exports. Other writing systems require a separately licensed font and are intentionally unavailable in this edition.
