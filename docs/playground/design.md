# Eidos Playground — first release

Design: white three-panel editor, charcoal UI typography, fine cool-gray dividers, lime #d5f87b selection and primary action. 64px toolbar; 216px section rail; flexible canvas; 264px inspector. Editor controls use the system sans family at 12–14px. Preview uses Georgia editorial display and system sans text, an olive #292e18 background, cream #f4f4e7 type, and line-based concentric SVG studies. The sample brand is fictional FORMA. No fabricated client claims.

Toolbar: Eidos / Playground, editable project name, undo/redo, desktop/mobile, Try page, Export. Sections rail: template, six selectable sections, reorder/hide controls, palette presets, project actions. Inspector: Content, Appearance, exact sliders, advanced controls. Narrow screens: toolbar wraps and rails become switchable full-width panels. Preview remains independently scrollable.

The saved approved preset is preserved verbatim. The original controller/optics source was not found in the current repository or glass-named branches. The portable renderer is therefore explicitly versioned eidos-portable-glass-1.0.0 and implements a frosted material with canvas edge lighting, not a claim of identical SVG live refraction. Renderer version is embedded in every project and export.

First release scope: local IndexedDB workspace and five snapshots; three template compositions; full JSON import/export; ZIP export; shared page markup, CSS, runtime; section editing and ordering; image uploads re-encoded into embedded assets; keyboard and mobile preview. No payment or cloud-account entitlement is claimed. Those are the next release after independent export validation.

Publication update: main received the original SVG optics in PRs #24 and #25 during this build. The branch now includes them under `src/lib/liquid-glass/`. The Playground still uses its versioned portable renderer; sharing the original optics between the preview and export is follow-up work.
