# Template usability and release acceptance — October 24, 2026

Brent requested reliable templates that customers can apply to their own needs.
The release promise is **no known blocking defects in the supported, tested
scope**, with evidence for the actual buyer files. It is not a claim of absolute
bug freedom or universal platform compatibility.

## Scoped implementation

This successor is based on affordable-draft PR141 at
`1cd53da6aefdfc11b2683357bcf23c063479d840`. It targets that branch, preserving the
held Playground/account pair and separate $25 pilot price pair. The three
private drafts advance from 0.1.0 to 0.1.1; no previously delivered archive is
rewritten. Proposed prices and unavailable commercial status remain intact.

- Every extracted draft includes `START-HERE.html` and `setup.js`. The helper
  reads the actual adjacent config, presents editable wording/contact/colors,
  and downloads a replacement `config.js`. There is no account, server, AI call,
  remote asset, persistence or new package dependency. Invalid email/color input
  and invalid or reversed calendar dates block the relevant download.
- The helper explicitly identifies the remaining source work: HTML fallbacks,
  other page copy, metadata, images, links, contrast and actual host setup. It
  does not claim complete no-code authoring or native builder import.
- Porchlight and Plainspoken previously left active forms in static HTML. If the
  runtime did not load, native GET submission could put entered values in a URL
  and hosting logs. Their fieldsets now start disabled and enable only after
  installing the local composer and all its handlers. A visible unavailable
  message remains if initialization fails. No message is represented as sent.
- Plainspoken's inquiry choices now use the same configured service names as
  its home/services pages. Existing stable service values preserve preselection.
- Long custom names and headlines reflow. Gatherline's calendar button is
  disabled until its local handler is installed. Existing host-page isolation,
  safe text rendering, calendar escaping and draft invalidation are retained.

## Required evidence

The scoped workflow builds exact ZIPs, checks their hashes/resources/links, then
opens extracted files under `file://`. It also opens each actual setup page,
downloads and replaces `config.js`, reloads the real site, and exercises the
configured calendar or contact draft. It checks configured service names,
recipient/body, draft invalidation, Unicode/quotes/newlines/HTML-like text,
long-word reflow at 1440/768/390/320, missing-script behavior and disabled
no-JavaScript controls. Existing page, asset, navigation, focus, portable-review,
calendar-injection and download assertions remain required.

Local package integrity, syntax and source checks are separate from rendered
evidence. This environment's cloud browser cannot reach the local server
(`ERR_CONNECTION_REFUSED`), and the official local Chromium download returned
invalid/truncated ZIPs. The existing isolated GitHub Actions browser workflow is
the fallback, with no assertion waived. Its exact final-source run and retained
receipt/screenshots must be read before marking rendered verification passed.
CI is verification, not deployment or a physical-device result.

## Customer acceptance applies to each edition

| Requirement | Acceptance evidence before claiming ready |
| --- | --- |
| Personalization | Use the purchased ZIP to replace real branding, services, images, contact details, page metadata and static fallbacks; no demo claims remain |
| Beginner setup | Observe a person with limited technical experience follow the guide, record where help is needed, publish to a supported host, open the public URL on a phone, and complete the intended action |
| Functional behavior | Every page/link/action works; missing scripts, invalid input, wrong files, long copy and unavailable integrations have honest, recoverable behavior |
| Responsive/accessibility | Actual desktop and phone checks, keyboard/focus, screen-reader review, browser zoom and reduced motion as applicable; automation is not certification |
| Platform claims | Test the exact edition on the actual named host/CMS/builder; a static source ZIP is not a universal theme importer |
| Purchase/delivery | Exact candidate and server price, signed TEST payment, delivery/hash association, recovery, refund/replay; preserve previous purchases and archives |
| Operations | Clear contents, support/license/refund scope, rollback copy and a reproducible defect path; no hidden mandatory Eidos subscription |

**Release remains held.** An automated setup walkthrough is useful evidence but
does not replace the observed novice publishing session. Actual destination,
physical-device/accessibility, final commercial terms and fulfillment gates
remain open for these drafts. The $25 pilot retains its own paired acceptance.
Do not publish a “100% bug-proof” or “beginner-ready” claim from these tests.
