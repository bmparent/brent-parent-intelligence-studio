# Decisions

- Preserve both current main revisions and existing unpublished work. Reuse scoped account/cloud implementations after inspecting and rerunning tests; do not merge historical editor snapshots wholesale.
- Catalogue claims come from actual project code/docs. Availability and verification are separate. Promo intake is not proof of organizer sorting; Wellway remains fictional.
- Retrieval: exact aliases score 100 plus task matches; task matches score 15 each; generic intents score 5. Bounded prior user questions resolve pronouns only when no explicit new project is named. Prior model output is never catalogue evidence.
- Passwords reuse asynchronous Node scrypt; OIDC uses JOSE signature/issuer/audience/nonce validation and Google subject identity. Existing account IDs and email-link access remain. Reference: https://developers.google.com/identity/openid-connect/reference and https://developers.google.com/identity/sign-in/web/backend-auth .
- Production authorization is a separate final release step after the concrete tested candidate. No live charges, raised allowances, new paid subscriptions or external messages.
