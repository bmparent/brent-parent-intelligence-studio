# Eidos Works Operating README

## Purpose

This Command Center is the private operating home for Eidos Works. Use it to move each lead, order, project, article, and follow-up toward a clear next action without scattering the source of truth across inboxes.

## Working rules

- Every active item has an owner, status, and next action.
- Link to the canonical file instead of making duplicate copies.
- Keep client-facing deliverables separate from internal working notes.
- Record only information needed to deliver the work.
- Never store passwords, API keys, card details, or unnecessary sensitive data in a Sheet or Doc.
- Move completed or obsolete material to `99_Archive`; do not delete business records casually.

## Daily rhythm

1. Review new leads and Snapshot orders.
2. Assign status, owner, due date, and next action.
3. Check active-project blockers and overdue tasks.
4. Process follow-ups before starting new non-urgent work.
5. Capture decisions in the appropriate project notes.

## Weekly rhythm

1. Complete the Weekly Review Template.
2. Reconcile pipeline, invoices/payments, and upcoming launches.
3. Select the next Insights topics from real customer questions.
4. Review indexing, schema, internal links, and AI referral notes.
5. Archive completed work and repair any broken canonical links.

## Status vocabulary

- Leads: New, Qualified, Discovery, Proposal, Won, Lost, Nurture
- Projects: Planned, Active, Blocked, Client Review, Launch Ready, Complete, Maintenance
- Tasks: Backlog, Ready, In Progress, Waiting, Done
- Content: Idea, Brief, Draft, Review, Scheduled, Published, Refresh

## Escalation

When an item is blocked, record the blocker, the person who can resolve it, the smallest next action, and the date it will be revisited. Do not leave “waiting” items without a follow-up date.
